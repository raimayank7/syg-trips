Plug type G: shape, countries and voltage

A type G plug has three rectangular pins. It is the British plug, with a fuse built into the plug and a shutter on the socket. 50 countries and territories in the IEC list use it, among them Bahrain, Bangladesh, Belize, Bhutan, Botswana, Brunei, Cambodia, Cyprus, Dominica, Falkland Islands, Gambia, Ghana.

Which plugs fit

A plug of this type fits only sockets of the same type. If you carry one, and you travel to a country that uses another type, you need an adapter. If you travel from India with type C chargers to a country that uses this type, check the country page: most narrow two-pin plugs will not fit these sockets without an adapter.

Voltage with this plug

Countries using type G run on 110 V, 220 V, 230 V and 240 V. A plug shape tells you nothing about the voltage, so always check the supply as well as the socket.
