Plug type C: shape, countries and voltage

A type C plug has two round pins. It is the small two-pin plug that most phone chargers, shavers and slim laptop adapters use around the world; it is often called the Europlug. 131 countries and territories in the IEC list use it, among them Afghanistan, Albania, Algeria, Andorra, Angola, Armenia, Austria, Azerbaijan, Bangladesh, Belarus, Belgium, Benin.

Which plugs fit

The narrow two-pin type C plug fits type C sockets and also the sockets of types E and F, which are the same size around the pins. That is why one two-pin charger works across most of continental Europe. It is made for low-power devices such as phone chargers and shavers, not for heavy appliances.

Voltage with this plug

Countries using type C run on 110 V, 115 V, 120 V, 127 V, 220 V, 230 V and 240 V. A plug shape tells you nothing about the voltage, so always check the supply as well as the socket.
