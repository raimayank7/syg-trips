Plug type F: shape, countries and voltage

A type F plug has two round pins with earth clips on the sides. It is the German style, often called Schuko, with metal clips at the top and bottom of the plug for the earth connection. 73 countries and territories in the IEC list use it, among them Afghanistan, Albania, Algeria, American Samoa, Andorra, Armenia, Aruba, Austria, Azerbaijan, Belarus, Bhutan, Bosnia and Herzegovina.

Which plugs fit

A type C two-pin plug fits this socket. A plug of this type does not fit sockets of other types without an adapter, and the type E and F plugs are not interchangeable in every case: a type E plug has a hole for the socket's earth pin, which a type F socket does not provide.

Voltage with this plug

Countries using type F run on 110 V, 120 V, 127 V, 220 V and 230 V. A plug shape tells you nothing about the voltage, so always check the supply as well as the socket.
