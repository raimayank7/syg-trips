Plug type A: shape, countries and voltage

A type A plug has two flat parallel pins. It is the North American two-pin plug, found on many phone chargers and small appliances with no earth pin. 53 countries and territories in the IEC list use it, among them American Samoa, Anguilla, Antigua and Barbuda, Aruba, Bahamas, Barbados, Belize, Bermuda, Bolivia, British Virgin Islands, Cambodia, Canada.

Which plugs fit

A plug of this type fits only sockets of the same type. If you carry one, and you travel to a country that uses another type, you need an adapter. If you travel from India with type C chargers to a country that uses this type, check the country page: most narrow two-pin plugs will not fit these sockets without an adapter.

Voltage with this plug

Countries using type A run on 100 V, 110 V, 115 V, 120 V, 127 V, 220 V, 230 V and 240 V. A plug shape tells you nothing about the voltage, so always check the supply as well as the socket.
